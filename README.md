# CW随手练

一个面向新手 HAM 的微信小程序，用于学习和练习 CW（莫尔斯码）。

## 功能

- 字母学习：A–Z、0–9 点播，配合字形图像和音节记忆法
- 字母听写：随机字符、重播、快捷输入、自动核对和结果统计
- 单词听写：按长度随机出词、播放、输入核对和结果统计
- 播放设置：5–60 WPM、400–900 Hz，采用标准 1:3:3:7 CW 时值

## 本地运行

1. 使用微信开发者工具导入本目录。
2. 在 `project.config.json` 中配置自己的小程序 AppID（如需要）。
3. 点击“编译”即可预览。
